# Plan przeglądu pod rozmowę z liderem (około 2 godziny)

**0–20 min — mapa i mechanika LLM:** 30, 31, 32, 33, 34. Odpowiedz: dlaczego model offline zna słowo „Warszawa”? Czym różni się słownik tokenów od wag i od wektorowej wyszukiwarki?

**20–50 min — prompt engineering:** 35, 36, 37, 38, 39. W laboratorium L napisz prompt z celem, źródłem, ograniczeniami, formatem i scenariuszem odmowy. Sprawdź w lab M, jak temperatura zmienia rozkład tokenów.

**50–75 min — NLP/statystyka/ewaluacja:** 40, 41, 42. Wytłumacz precision, recall, golden set i faithfulness, a następnie wskaż różnicę retrieval failure/generation failure.

**75–100 min — produkcja:** 43, 44, 45, 46. Przećwicz, co wersjonujesz i monitorujesz. Użyj lab N do wyboru metody.

**100–120 min — rozmowa z liderem:** 47, 48 i stare 18–25. Narysuj architekturę Azure i opisz kryterium go/no-go po zmianie promptu.
