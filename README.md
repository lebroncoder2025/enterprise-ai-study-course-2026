# Enterprise AI Study Course

Free, self-paced interactive study material for AI engineering, ML, agent workflows, RAG, cloud operations, validation and MLOps. The package includes a 17-panel enterprise screen lab, static PNG previews, quizzes, a short refresher course and local Polish video animations.

Open `index.html` to begin. The core lessons and examples are static and work offline after download. Links to vendor documentation and selected external videos require internet access.

All interface panels, project names and data are educational illustrations. No company tenant screenshots or personal application documents are included.
