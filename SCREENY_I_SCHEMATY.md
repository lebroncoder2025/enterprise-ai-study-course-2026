# Screenshoty: co jest autentyczne, a co schematem edukacyjnym

## Autentyczne screenshoty — internet

W lekcjach 02, 05, 08, 22, 23 zostały użyte bezpośrednie obrazy z publicznych materiałów dostawców, w tym:

- **Microsoft Foundry** — wybór projektu, konfiguracja agenta, ustawienia modelu, workflow: https://microsoftlearning.github.io/mslearn-ai-agents/Instructions/Exercises/06-build-workflow-ms-foundry.html
- **Azure Portal / App Service** — wyszukiwanie App Services, tworzenie Web App, ustawienia wdrożenia: https://learn.microsoft.com/en-us/azure/app-service/quickstart-python
- **Azure AI Search** — Import data, Search Explorer: https://learn.microsoft.com/en-us/azure/search/search-get-started-portal
- **Copilot Studio** — create agent, knowledge, kanał Teams: https://learn.microsoft.com/en-us/microsoft-copilot-studio/overview
- **VS Code / GitHub Copilot** — instrukcje repo i narzędzia agentowe: https://code.visualstudio.com/docs/copilot/customization/overview

Zdjęcia **nie są lokalnymi kopiami** w paczce. Aby je zobaczyć, połącz się z internetem. Zewnętrzne serwery mogą zmieniać ścieżki obrazów i interfejs. Nie należy mylić zrzutu z bieżącym stanem własnego tenanta.
